# v0.13.0: 2026-09-27

## Vox Agents

- Tracing and usage data now show more of the evaluation, execution, and model-routing process, making it easier to inspect what happened during a turn.
- Improved Codex and Claude Code reliability and model discovery, including a fix for dropped Codex proxy connections.
- Civ V can now launch without needing to start the game twice.

## Fixes and Reliability

- Fixed paused strategist turns being lost, so they resume when the game is unpaused.
- Fixed diplomacy chat launch passing the wrong value for the selected diplomat or voice.
- Fixed a crash in tactical snapshot capture involving barbarians or non-major cities.
- Improved launcher startup checks and limited failure log output to the current launch.
